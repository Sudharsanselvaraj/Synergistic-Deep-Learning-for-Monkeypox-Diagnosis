# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 2.0.x | ✅ |
| < 2.0 | ❌ (archived original) |

## Reporting a Vulnerability

Please report security issues privately by opening a
[GitHub security advisory](https://github.com/Sudharsanselvaraj/Synergistic-Deep-Learning-for-Monkeypox-Diagnosis/security/advisories/new)
rather than a public issue. We will acknowledge receipt within a reasonable timeframe and keep
you informed of remediation progress.

## Scope & Disclaimer

Tri-Net v2 is a **research artifact**, not a certified medical device. It must not be used for
real clinical diagnosis without appropriate regulatory approval and clinical validation. Do not
commit credentials (e.g., `kaggle.json`) — they are git-ignored by default.
