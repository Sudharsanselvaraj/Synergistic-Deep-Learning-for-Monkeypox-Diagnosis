## Usage

```bash
# download fusion.weights.h5 + fusion_meta.json from the Release into outputs/checkpoints/
trinet predict path/to/lesion.jpg
```

Or in Python:

```python
from trinet.inference.predict import predict_image
print(predict_image("lesion.jpg"))
```

All numbers are regenerated by `trinet benchmark`; see [benchmark.md](benchmark.md).
