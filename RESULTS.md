# Tri-Net v2 — Results (honest, reproducible)

All numbers below are produced by runnable code from a **leakage-free 14-class split**
(2426 train / 303 val / 303 test unique images) and regenerated by the `src/` pipeline —
nothing is hand-typed. This replaces the original published paper's unreproducible claims.

## Headline progression

| Version | Test accuracy |
|---|---:|
| Reproducible Tri-Net (paper's 3 backbones, Mean/PSO) | 72.6% |
| + ConvNeXt-Tiny backbone (Mean ensemble) | 75.25% |
| **+ Concat+MLP feature fusion (champion)** | **77.23%** |

Net gain over the reproducible baseline: **+4.63 percentage points** (77.23 − 72.60).
Ensemble oracle ceiling (from the diversity analysis) is ~80%, so the fusion captures most of
the available headroom.

## Single-backbone benchmark (frozen features, same pipeline)

| Backbone | Accuracy | Macro-F1 | AUC | κ |
|---|---:|---:|---:|---:|
| EfficientNetB4 | 58.4 | 63.3 | 95.0 | 54.2 |
| DenseNet201 | 66.3 | 67.2 | 95.6 | 62.8 |
| InceptionResNetV2 | 68.0 | 68.8 | 96.2 | 64.4 |
| **ConvNeXt-Tiny** | **69.3** | **70.3** | **96.5** | **65.9** |

*EfficientNetV2-S is pending (hangs on tensorflow-metal; requires a CPU extraction run).*

## Experimental narrative (well-supported conclusions)

1. **Modern representations help.** ConvNeXt-Tiny > InceptionResNetV2 > DenseNet201 >
   EfficientNetB4 under identical frozen-feature training.
2. **Feature fusion beats probability fusion.** Concat+MLP > Mean > PSO.
3. **More capacity is not automatically better.** Under the current dataset size and training
   protocol, the higher-capacity fusion modules (Transformer, gated attention) did **not
   generalize as well** as the lower-capacity Concat+MLP fusion. This is a statement about the
   data/training regime, not an inherent limitation of those architectures.
4. **Fine-tuning does not help** at this data scale — a valid negative result. Unfreezing
   backbone layers on ~2.4k images overfits immediately; the fine-tuned ensemble (72.6%)
   matches the frozen ensemble.
5. **The symptom module's 97.86% does not reproduce.** No standard model (CNN / LR / RF /
   XGBoost, with or without the original `sum` feature) exceeds ~70% on the (largely synthetic)
   symptom dataset.
6. **Ensemble robustness is variance reduction.** Base models are moderately diverse (pairwise
   disagreement ~29%, error-correlation ~0.38), so the ensemble reduces variance rather than
   averaging near-identical classifiers.

## Honesty notes

- The 77.23% is on a demanding benchmark: 14 classes, leakage-free, ~3,000 real images,
  reproducible split, cross-validated. Many published Mpox studies report 95–99% on binary or
  4-class tasks with augmentation leakage — not comparable.
- We do **not** attempt to recover the published 97.86%. The contribution is a reproducible
  benchmark with well-supported conclusions about which architectures and fusion strategies
  genuinely help.

## Reproduce

```bash
make venv && make data && make prep && make features && make base
make pso && make eval && python -m src.models.fusion        # image pipeline + fusion ablation
python -m src.eval.run_all --champion                        # figures from the 77.23% model
python -m src.eval.diversity && python -m src.eval.cross_val
```

(Phase-1 tables preserved under `results/tables/phase1/`).
